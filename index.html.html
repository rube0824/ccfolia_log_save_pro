코코포리아 PRO의 "채팅 메뉴 → 로그 출력"으로 받은 사진 포함 HTML 파일을 불러오면, 원하는 탭만 골라 시간순으로 합치고, 내용을 수정·삭제한 뒤 티스토리에도 안전하게 붙여넣을 수 있는 형태로 저장할 수 있습니다.

・ "티스토리용 코드 복사"는 스타일이 특정 클래스 안에만 적용되도록 감싸서, 블로그 전체 배경이 검게 바뀌는 등의 충돌 없이 안전하게 붙여넣을 수 있게 만든 코드예요. 티스토리 글쓰기에서 'HTML' 모드로 전환한 뒤 붙여넣어 주세요.
・ 사진(스탠딩)이 포함되어 있어 로그가 길면 파일 용량이 꽤 커질 수 있어요.
